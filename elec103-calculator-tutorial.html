Getting oriented

A few habits make everything below go smoothly. The simulator behaves like the real hardware: you build an expression on the home screen, then press ENTER to evaluate it. Results stack up the screen, and the last answer is reusable.

Set the angle mode first

Trigonometry gives different numbers in degrees versus radians. Choose deliberately.

Keys

MODE▲▼ row · ◀ ▶ change · CLEAR to leave
Rule of thumb: physics and engineering examples here assume Degree mode unless noted. The current setting is shown on the MODE screen and in the simulator’s side panel.

Choose how numbers are displayed

The NUMBER row on the same MODE screen controls the format of every result.

MODENUMBER rowNORMAL · SCI · ENG
  • NORMAL — plain decimals until the value gets very large or small.
  • SCI — one digit before the point: 4700 becomes 4.7E3.
  • ENG — the exponent is always a multiple of three, so it lines up with the SI prefixes: 4700 becomes 4.7E3 (4.7 k) and 0.0022 becomes 2.2E−3 (2.2 m).
The DECIMAL row below fixes the number of decimal places (FIX 2) or leaves it free (FLOAT).

Type with your keyboard

You do not have to click every key. With the simulator focused, your keyboard drives it directly.

  • Digits and . type numbers; + - * / ^ ( ) , are the operators.
  • Enter evaluates, Backspace deletes, arrow keys navigate, Esc is QUIT.
  • Letters type as ALPHA characters, so sin(30) and Ans can be typed out in full.
  • E gives the power-of-ten exponent: 4.7E3.
If typing stops working, click the calculator once — a dropdown in the side panel had the keyboard.

Reuse the last answer

Every result is stored in Ans. Start a new line with an operator and it inserts Ans automatically, or call it directly.

Keys

2nd(−)→ Ans

Example: after computing a current, type × 2 2 0 ENTER to multiply the previous answer by 220.

The 2nd and ALPHA modifiers

Most keys carry three meanings: the printed face, a blue label (after 2nd), and a green letter (after ALPHA). Store a value to a variable with STO▸, which arms ALPHA so you can pick the letter.

5STO▸A5→A

Fixing a typo

DEL removes the character at the cursor; CLEAR wipes the current line. Arrow keys move through a long expression so you can edit in place before pressing ENTER.

Implicit multiplication works: 2A, 3(4+1), and 2π all evaluate as products.

Engineering notation and SI prefixes

Show 4700 and 0.0022 the way engineers write them.

Set MODE → NUMBER row → ENG, then CLEAR to return to the home screen. Every result now comes back with an exponent that is a multiple of three.

Keys

4700ENTER
Display4.7E3
.0022ENTER
Display2.2E−3

Because the exponent moves in steps of three, it maps straight onto the prefixes: E9 = G, E6 = M, E3 = k, E−3 = m, E−6 = µ, E−9 = n, E−12 = p. So 4.7E3 reads 4.7 k and 2.2E−3 reads 2.2 m.

Unlike SCI, ENG keeps the exponent even when it is zero: 10 displays as 10E0 and 240000 as 240E3. The mantissa always lands between 1 and 999.999.

Solve a linear system with matrices

2x + 3y = 8 · x − y = −1

Write it as [A]·X = [B] with A = [[2, 3],[1, −1]] and B = [[8],[−1]]. Then X = [A]⁻¹[B].

  1. Open the matrix editor: 2nd x⁻¹ MATRIX → EDIT → [A].
  2. Set dimensions 2 × 2, then enter 2, 3, 1, −1 (press ENTER after each, using (−) for the negative).
  3. Back to 2nd x⁻¹ → EDIT → [B]; set 2 × 1 and enter 8, −1.
  4. Quit to the home screen (2nd MODE), then build [A]⁻¹[B]: insert [A] via MATRIX → NAMES → [A], press x⁻¹, then insert [B] the same way and press ENTER.
Display[[1] [2]] → x = 1, y = 2
The determinant is on the same menu: MATRIX → MATH → det( then NAMES → [A] gives −5, confirming the system has a unique solution.

TI-BASIC Programs

Type a program once and reuse it forever. These five run as-is on the simulator. To enter one: press PRGM → + New program, give it a name, then type the code (the editor takes your keyboard, and pressing PRGM inside the editor inserts commands such as Disp and If). Quit with 2nd MODE, then run it from PRGM → choose the program → Run.

The Copy button puts the source on your clipboard. You can paste it directly into the program editor instead of typing it key by key. Symbols to note: → is the STO▸ key, ² is x², and √( is 2nd x².

Quadratic formula

QUADRATIC

Solves a·x² + b·x + c = 0 and reports both real roots (or a no-real-roots message).

Prompt A
Prompt B
Prompt C
B²-4AC→D
If D<0
Then
Disp "NO REAL ROOTS"
Stop
End
(-B+√(D))/(2A)→M
(-B-√(D))/(2A)→N
Disp "X1=",M
Disp "X2=",N

Sample run: A = 1, B = −5, C = 6 → X1 = 3, X2 = 2.

Ohm’s law + power

OHMS

Enter current and resistance; returns voltage and dissipated power.

Prompt I
Prompt R
I*R→V
I²*R→P
Disp "V (volts)=",V
Disp "P (watts)=",P

Sample run: I = 0.5, R = 220 → V = 110, P = 55.

Parallel resistance

RPAR

Combines two resistors in parallel using the reciprocal key.

Prompt R
Prompt S
(R⁻¹+S⁻¹)⁻¹→T
Disp "RP (ohms)=",T

Sample run: R = 100, S = 100 → RP = 50.

Projectile range

RANGE

Launch speed and angle in; horizontal range out. Set Degree mode first.

Prompt V
Prompt A
V²*sin(2A)/9.8→R
Disp "RANGE (m)=",R

Sample run: V = 20, A = 30 → RANGE ≈ 35.35.

Compound interest

COMPND

Principal, annual rate, periods per year, and years in; final amount out.

Prompt P
Prompt R
Prompt N
Prompt T
P(1+R/N)^(N*T)→F
Disp "AMOUNT=",F

Sample run: P = 1000, R = .05, N = 12, T = 10 → AMOUNT ≈ 1647.01.
