Problem 1
Ch. 6 — Branch Current by Ohm's Law
A $9.0\ \mathrm{V}$ source is connected across two resistors in parallel: $R_1 = 330\ \Omega$ and $R_2 = 1.5\ \mathrm{k\Omega}$. Find the current in the $R_1$ branch, in milliamperes.
Two parallel branches across a 9.0 V source
Find the current $I_1$ in the $330\ \Omega$ branch.
Solution
27.3 mA
Step 1List the knowns: $V_S = 9.0\ \mathrm{V}$, $R_1 = 330\ \Omega$, $R_2 = 1.5\ \mathrm{k\Omega}$. Asked: the current $I_1$ in the $R_1$ branch.
Step 2Describe the model: both resistors connect between the same two nodes A and B, so they are in parallel. Assume an ideal source and ideal wires.
Step 3Set the sign convention: conventional current flows out of the source's positive terminal and down through each branch from node A to node B; take that direction as positive.
Step 4Apply the parallel voltage rule: the voltage across every branch is the same, so $$V_1 = V_S$$
Step 5Write Ohm's law for the branch alone: $$I_1 = \frac{V_S}{R_1}$$ It applies because $R_1$ has the full source voltage across it.
Step 6Substitute the numbers: $$I_1 = \frac{9.0\ \mathrm{V}}{330\ \Omega}$$
Step 7Solve: $I_1 = 0.02727\ \mathrm{A}$.
Step 8State the result: $I_1 = 27.3\ \mathrm{mA}$, flowing from node A down through $R_1$ to node B.
Step 9Check reasonableness: $\mathrm{V}/\Omega = \mathrm{A}$, and the $1.5\ \mathrm{k\Omega}$ branch never entered the calculation. It carries its own $6.00\ \mathrm{mA}$; the smaller resistance carries the larger current, as expected.
Worked Solution
Given: $V_S = 9.0\ \mathrm{V}$, $R_1 = 330\ \Omega$, $R_2 = 1.5\ \mathrm{k\Omega}$. In a parallel circuit every branch has the full source voltage across it, so $V_1 = V_S$. Ohm's law on the branch alone: $$I_1 = \frac{V_S}{R_1} = \frac{9.0\ \mathrm{V}}{330\ \Omega} = 0.0273\ \mathrm{A} = 27.3\ \mathrm{mA}$$ Units: $\mathrm{V}/\Omega = \mathrm{A}$. The $R_2$ branch draws its own $9.0/1500 = 6.00\ \mathrm{mA}$ independently and does not affect $I_1$.
Problem 2
Ch. 6 — Kirchhoff's Current Law at a Node
A source supplies a total of $85\ \mathrm{mA}$ to four parallel branches. Clamp-meter readings on three of the branches are $I_1 = 22\ \mathrm{mA}$, $I_2 = 17.5\ \mathrm{mA}$ and $I_3 = 31\ \mathrm{mA}$. Find the current in the fourth branch.
Total current splitting into four branches at node A
Find the fourth branch current $I_4$.
Solution
14.5 mA
Step 1List the knowns: $I_T = 85\ \mathrm{mA}$ into the node; $I_1 = 22\ \mathrm{mA}$, $I_2 = 17.5\ \mathrm{mA}$, $I_3 = 31\ \mathrm{mA}$ leaving. Asked: $I_4$.
Step 2Describe the model: all four branches leave the same node A, and charge cannot pile up or vanish at a node.
Step 3Set the sign convention: current arriving at node A is positive in; the four branch currents are positive out.
Step 4Write Kirchhoff's current law at node A: $$I_T = I_1 + I_2 + I_3 + I_4$$ It applies because the total current into a node equals the total current out.
Step 5Rearrange for the unknown: $$I_4 = I_T - (I_1 + I_2 + I_3)$$
Step 6Substitute the numbers: $$I_4 = 85\ \mathrm{mA} - (22 + 17.5 + 31)\ \mathrm{mA}$$
Step 7Simplify: the three known branches account for $70.5\ \mathrm{mA}$, so $I_4 = 85 - 70.5$.
Step 8State the result: $I_4 = 14.5\ \mathrm{mA}$, leaving node A through the fourth branch.
Step 9Check: $22 + 17.5 + 31 + 14.5 = 85\ \mathrm{mA}$, which matches the total, and no resistances were needed.
Worked Solution
Given: $I_T = 85\ \mathrm{mA}$, $I_1 = 22\ \mathrm{mA}$, $I_2 = 17.5\ \mathrm{mA}$, $I_3 = 31\ \mathrm{mA}$. KCL at the top node: current in equals current out, $$I_T = I_1 + I_2 + I_3 + I_4$$ $$I_4 = I_T - (I_1 + I_2 + I_3) = 85 - (22 + 17.5 + 31) = 85 - 70.5 = 14.5\ \mathrm{mA}$$ All terms are in mA, so the result is in mA. No resistance values are needed.
Problem 3
Ch. 6 — Finding an Unknown Branch Resistance
Three resistors are in parallel across a $24\ \mathrm{V}$ source: $R_1 = 1.2\ \mathrm{k\Omega}$, $R_2 = 2.7\ \mathrm{k\Omega}$ and an unmarked resistor $R_X$. An ammeter in series with the source reads a total current of $40\ \mathrm{mA}$. Determine $R_X$.
Three parallel branches with one unmarked resistor
Determine the resistance $R_X$.
Solution
2.16 kΩ
Free-body diagram
Assumed current directions at the top node
Step 1Draw the diagram: sketch the three branches between nodes A and B, with $I_T$ entering node A and $I_1$, $I_2$, $I_3$ flowing down through $R_1$, $R_2$, $R_X$.
Step 2List the knowns: $V_S = 24\ \mathrm{V}$, $R_1 = 1.2\ \mathrm{k\Omega}$, $R_2 = 2.7\ \mathrm{k\Omega}$, $I_T = 40\ \mathrm{mA}$. Asked: $R_X$.
Step 3Set the sign convention: current into node A is positive in; branch currents down from A to B are positive out. Every branch has $24\ \mathrm{V}$ across it.
Step 4Write Ohm's law for each known branch: $$I_1 = \frac{V_S}{R_1}, \qquad I_2 = \frac{V_S}{R_2}$$
Step 5Substitute the numbers: $$I_1 = \frac{24\ \mathrm{V}}{1200\ \Omega} = 20.0\ \mathrm{mA}, \qquad I_2 = \frac{24\ \mathrm{V}}{2700\ \Omega} = 8.89\ \mathrm{mA}$$
Step 6Write KCL at node A: $$I_3 = I_T - I_1 - I_2$$ The unknown branch carries whatever the other two do not.
Step 7Substitute into KCL: $$I_3 = 40 - 20.0 - 8.89 = 11.11\ \mathrm{mA}$$
Step 8Write Ohm's law for the unknown branch: $$R_X = \frac{V_S}{I_3}$$
Step 9Substitute and solve: $$R_X = \frac{24\ \mathrm{V}}{0.01111\ \mathrm{A}} = 2160\ \Omega$$ So $R_X = 2.16\ \mathrm{k\Omega}$.
Step 10Check: total resistance is $24\ \mathrm{V} / 40\ \mathrm{mA} = 600\ \Omega$, below the smallest branch ($1.2\ \mathrm{k\Omega}$), and $R_X$ sits between $R_1$ and $R_2$ just as $I_3$ sits between $I_1$ and $I_2$.
Worked Solution
Assumed current directions at the top node
Given: $V_S = 24\ \mathrm{V}$, $R_1 = 1.2\ \mathrm{k\Omega}$, $R_2 = 2.7\ \mathrm{k\Omega}$, $I_T = 40\ \mathrm{mA}$. Each branch sees $24\ \mathrm{V}$: $$I_1 = \frac{24}{1200} = 20.0\ \mathrm{mA}, \qquad I_2 = \frac{24}{2700} = 8.89\ \mathrm{mA}$$ KCL: $$I_3 = I_T - I_1 - I_2 = 40 - 20.0 - 8.89 = 11.11\ \mathrm{mA}$$ Ohm's law on the unknown branch: $$R_X = \frac{V_S}{I_3} = \frac{24\ \mathrm{V}}{0.01111\ \mathrm{A}} = 2160\ \Omega = 2.16\ \mathrm{k\Omega}$$ Check: $R_T = 24/0.040 = 600\ \Omega$, below the smallest branch.
Problem 4
Ch. 6 — Equal Resistors in Parallel
A technician needs a resistance that is not in the parts drawer and builds it by connecting five identical $2.2\ \mathrm{k\Omega}$ resistors in parallel. Find the total resistance of the combination.
Find the total resistance $R_T$.
Solution
440 Ω
Step 1List the knowns: $n = 5$ identical resistors, each $R = 2.2\ \mathrm{k\Omega}$. Asked: total resistance $R_T$.
Step 2Describe the model: all five resistors connect between the same two nodes, so they are in parallel and each offers an identical path.
Step 3Set the convention: work in ohms, $R = 2200\ \Omega$; no current direction is needed for a resistance calculation.
Step 4Write the equal-branch shortcut: $$R_T = \frac{R}{n}$$ It applies only because every branch has the same value.
Step 5Substitute the numbers: $$R_T = \frac{2200\ \Omega}{5}$$
Step 6Solve: $R_T = 440\ \Omega$.
Step 7State the result: the five-resistor combination behaves as a single $440\ \Omega$ resistor.
Step 8Check: $440\ \Omega$ is smaller than the smallest branch ($2200\ \Omega$), as a parallel total must be, and each resistor carries only one fifth of the current, so the power is spread across five parts.
Worked Solution
Given: $n = 5$ equal branches, each $R = 2.2\ \mathrm{k\Omega} = 2200\ \Omega$. For equal parallel resistors: $$R_T = \frac{R}{n} = \frac{2200\ \Omega}{5} = 440\ \Omega$$ Check with reciprocals: $5 \cdot \frac{1}{2200} = 2.273\ \mathrm{mS}$, and $1/2.273\ \mathrm{mS} = 440\ \Omega$. The result is below the smallest branch.
Problem 5
Ch. 6 — Product Over Sum
Resistors $R_1 = 4.7\ \mathrm{k\Omega}$ and $R_2 = 6.8\ \mathrm{k\Omega}$ are connected in parallel. Use the two-resistor shortcut to find the total resistance.
Two resistors in parallel between nodes A and B
Find the total resistance $R_T$.
Solution
2.78 kΩ
Step 1List the knowns: $R_1 = 4.7\ \mathrm{k\Omega}$, $R_2 = 6.8\ \mathrm{k\Omega}$ in parallel. Asked: $R_T$.
Step 2Describe the model: both ends of each resistor land on the same two nodes A and B, so this is exactly two branches in parallel.
Step 3Set the convention: convert to ohms to keep the units of the product clear, $R_1 = 4700\ \Omega$ and $R_2 = 6800\ \Omega$.
Step 4Write the product-over-sum rule: $$R_T = \frac{R_1 \cdot R_2}{R_1 + R_2}$$ It applies because there are exactly two branches.
Step 5Substitute the numbers: $$R_T = \frac{4700\ \Omega \cdot 6800\ \Omega}{4700\ \Omega + 6800\ \Omega}$$
Step 6Simplify the top and bottom: product $= 31\,960\,000\ \Omega^2$, sum $= 11\,500\ \Omega$.
Step 7Divide: $R_T = 31\,960\,000 / 11\,500 = 2779\ \Omega$.
Step 8State the result: $R_T = 2.78\ \mathrm{k\Omega}$.
Step 9Check: $\Omega^2/\Omega = \Omega$, and $2.78\ \mathrm{k\Omega}$ is below the smaller branch, $4.7\ \mathrm{k\Omega}$, as every parallel result must be.
Worked Solution
Given: $R_1 = 4700\ \Omega$, $R_2 = 6800\ \Omega$. Product over sum: $$R_T = \frac{R_1 \cdot R_2}{R_1 + R_2} = \frac{4700 \cdot 6800}{4700 + 6800} = \frac{31\,960\,000\ \Omega^2}{11\,500\ \Omega} = 2779\ \Omega = 2.78\ \mathrm{k\Omega}$$ Units: $\Omega^2/\Omega = \Omega$. Check: $2.78\ \mathrm{k\Omega} < 4.7\ \mathrm{k\Omega}$.
Problem 6
Ch. 6 — Reciprocal Formula with Four Branches
Four resistors are connected in parallel: $R_1 = 470\ \Omega$, $R_2 = 680\ \Omega$, $R_3 = 1.0\ \mathrm{k\Omega}$ and $R_4 = 2.2\ \mathrm{k\Omega}$. Find the total resistance by adding the branch conductances.
Four parallel branches between nodes A and B
Find the total resistance $R_T$.
Solution
198 Ω
Step 1List the knowns: $R_1 = 470\ \Omega$, $R_2 = 680\ \Omega$, $R_3 = 1.0\ \mathrm{k\Omega}$, $R_4 = 2.2\ \mathrm{k\Omega}$, all in parallel. Asked: $R_T$.
Step 2Describe the model: four branches share nodes A and B. Each added branch gives current another route, so conductances add.
Step 3Set the convention: work in ohms and siemens, with $G = 1/R$ and $1\ \mathrm{mS} = 10^{-3}\ \mathrm{S}$.
Step 4Write the reciprocal formula: $$\frac{1}{R_T} = \frac{1}{R_1} + \frac{1}{R_2} + \frac{1}{R_3} + \frac{1}{R_4}$$ It applies to any number of parallel branches.
Step 5Substitute the numbers: $$\frac{1}{R_T} = \frac{1}{470} + \frac{1}{680} + \frac{1}{1000} + \frac{1}{2200}\ \ \mathrm{S}$$
Step 6Compute each conductance: $2.128\ \mathrm{mS}$, $1.471\ \mathrm{mS}$, $1.000\ \mathrm{mS}$, $0.455\ \mathrm{mS}$.
Step 7Add them: $1/R_T = 5.053\ \mathrm{mS}$. This is one over the total, not the total.
Step 8Invert the sum: $$R_T = \frac{1}{5.053 \times 10^{-3}\ \mathrm{S}} = 197.9\ \Omega$$
Step 9State the result: $R_T = 198\ \Omega$.
Step 10Check: $198\ \Omega$ is below the smallest branch ($470\ \Omega$). An answer above $470\ \Omega$ would signal a forgotten inversion.
Worked Solution
Given: $R_1 = 470\ \Omega$, $R_2 = 680\ \Omega$, $R_3 = 1000\ \Omega$, $R_4 = 2200\ \Omega$. Conductance adds in parallel: $$\frac{1}{R_T} = \frac{1}{R_1} + \frac{1}{R_2} + \frac{1}{R_3} + \frac{1}{R_4}$$ $$\frac{1}{R_T} = 2.128 + 1.471 + 1.000 + 0.455 = 5.053\ \mathrm{mS}$$ Invert the sum: $$R_T = \frac{1}{5.053 \times 10^{-3}\ \mathrm{S}} = 197.9\ \Omega \approx 198\ \Omega$$ Check: $198\ \Omega < 470\ \Omega$, the smallest branch.
Problem 7
Ch. 6 — Current Sources in Parallel
Three ideal current sources are connected in parallel with a load resistor. Sources $I_A = 15\ \mathrm{mA}$ and $I_B = 40\ \mathrm{mA}$ both point up toward the top node; source $I_C = 10\ \mathrm{mA}$ points down, away from the top node. Find the net current delivered to the load.
Three current sources in parallel with a load
Find the net current $I_{net}$ delivered to the load.
Solution
45.0 mA
Step 1List the knowns: $I_A = 15\ \mathrm{mA}$ up, $I_B = 40\ \mathrm{mA}$ up, $I_C = 10\ \mathrm{mA}$ down. Asked: net current into the load.
Step 2Describe the model: all three sources and the load share the same two nodes, so the sources are in parallel. Each ideal source delivers its set current regardless of the load.
Step 3Set the sign convention: current pushed up into the top node is positive; current pulled down out of the top node is negative.
Step 4Write the rule for parallel current sources: $$I_{net} = I_A + I_B - I_C$$ Parallel current sources add algebraically, just as series voltage sources do.
Step 5Substitute the numbers: $$I_{net} = 15\ \mathrm{mA} + 40\ \mathrm{mA} - 10\ \mathrm{mA}$$
Step 6Solve: $I_{net} = 45\ \mathrm{mA}$.
Step 7State the result: a net $45.0\ \mathrm{mA}$ enters the top node and flows down through $R_L$.
Step 8Check with KCL at the top node: $15 + 40 = 55\ \mathrm{mA}$ in, and $10 + 45 = 55\ \mathrm{mA}$ out. The node balances.
Worked Solution
Given: $I_A = 15\ \mathrm{mA}$ (up), $I_B = 40\ \mathrm{mA}$ (up), $I_C = 10\ \mathrm{mA}$ (down). Current sources in parallel add algebraically, with direction respected. Taking up (into the top node) as positive: $$I_{net} = I_A + I_B - I_C = 15 + 40 - 10 = 45\ \mathrm{mA}$$ The net $45\ \mathrm{mA}$ enters the top node and flows down through the load.
Problem 8
Ch. 6 — Two-Branch Current Divider
A total current of $50\ \mathrm{mA}$ arrives at a node and divides between two parallel branches, $R_1 = 1.5\ \mathrm{k\Omega}$ and $R_2 = 3.3\ \mathrm{k\Omega}$. Find the current in the $R_1$ branch.
A 50 mA total dividing between two branches
Find the current $I_1$ in the $R_1$ branch.
Solution
34.4 mA
Step 1List the knowns: $I_T = 50\ \mathrm{mA}$, $R_1 = 1.5\ \mathrm{k\Omega}$, $R_2 = 3.3\ \mathrm{k\Omega}$. Asked: $I_1$.
Step 2Describe the model: the two resistors share nodes A and B, so the voltage is common and the current divides in inverse proportion to resistance.
Step 3Set the sign convention: $I_T$ enters node A; $I_1$ and $I_2$ flow down through $R_1$ and $R_2$ to node B and are positive in that direction.
Step 4Write the two-branch current divider: $$I_1 = \frac{R_2}{R_1 + R_2} \cdot I_T$$ Note the opposite branch's resistance goes on top.
Step 5Substitute the numbers: $$I_1 = \frac{3.3\ \mathrm{k\Omega}}{1.5\ \mathrm{k\Omega} + 3.3\ \mathrm{k\Omega}} \cdot 50\ \mathrm{mA}$$
Step 6Simplify the fraction: $3.3 / 4.8 = 0.6875$, a pure number because the kilohms cancel.
Step 7Multiply: $I_1 = 0.6875 \cdot 50\ \mathrm{mA} = 34.375\ \mathrm{mA}$.
Step 8State the result: $I_1 = 34.4\ \mathrm{mA}$ down through $R_1$.
Step 9Check: the remaining $15.6\ \mathrm{mA}$ flows in $R_2$, and both branches give the same voltage, $34.4\ \mathrm{mA} \cdot 1.5\ \mathrm{k\Omega} = 15.6\ \mathrm{mA} \cdot 3.3\ \mathrm{k\Omega} = 51.6\ \mathrm{V}$. The smaller resistor took the larger share.
Worked Solution
Given: $I_T = 50\ \mathrm{mA}$, $R_1 = 1.5\ \mathrm{k\Omega}$, $R_2 = 3.3\ \mathrm{k\Omega}$. Two-branch current divider, with the opposite resistor on top: $$I_1 = \frac{R_2}{R_1 + R_2} \cdot I_T = \frac{3.3}{1.5 + 3.3} \cdot 50\ \mathrm{mA} = 0.6875 \cdot 50\ \mathrm{mA} = 34.4\ \mathrm{mA}$$ The resistance ratio is dimensionless, so the answer is in mA. Then $I_2 = 50 - 34.4 = 15.6\ \mathrm{mA}$.
Problem 9
Ch. 6 — General Current Divider, Three Branches
A total current of $120\ \mathrm{mA}$ flows into three parallel branches: $R_1 = 1.0\ \mathrm{k\Omega}$, $R_2 = 2.2\ \mathrm{k\Omega}$ and $R_3 = 4.7\ \mathrm{k\Omega}$. Use the general current divider rule to find the current in the $R_2$ branch.
A 120 mA total dividing among three branches
Find the current $I_2$ in the $R_2$ branch.
Solution
32.7 mA
Free-body diagram
Assumed branch currents for the three-way divider
Step 1Draw the diagram: sketch $I_T$ entering node A and $I_1$, $I_2$, $I_3$ flowing down through the three branches to node B; mark the whole group as $R_T$.
Step 2List the knowns: $I_T = 120\ \mathrm{mA}$, $R_1 = 1.0\ \mathrm{k\Omega}$, $R_2 = 2.2\ \mathrm{k\Omega}$, $R_3 = 4.7\ \mathrm{k\Omega}$. Asked: $I_2$.
Step 3Set the sign convention: branch currents are positive downward from A to B. The two-branch shortcut does not apply because there are three branches.
Step 4Write the reciprocal formula for the total: $$\frac{1}{R_T} = \frac{1}{R_1} + \frac{1}{R_2} + \frac{1}{R_3}$$
Step 5Substitute the numbers: $$\frac{1}{R_T} = \frac{1}{1000} + \frac{1}{2200} + \frac{1}{4700}\ \ \mathrm{S} = 1.000 + 0.4545 + 0.2128\ \ \mathrm{mS}$$
Step 6Add and invert: $1/R_T = 1.667\ \mathrm{mS}$, so $R_T = 599.8\ \Omega$.
Step 7Write the general current divider rule: $$I_2 = \frac{R_T}{R_2} \cdot I_T$$ The branch's own resistance goes underneath.
Step 8Substitute the numbers: $$I_2 = \frac{599.8\ \Omega}{2200\ \Omega} \cdot 120\ \mathrm{mA}$$
Step 9Solve and state the result: $I_2 = 0.2726 \cdot 120\ \mathrm{mA} = 32.7\ \mathrm{mA}$ down through $R_2$.
Step 10Check: the common voltage is $0.120\ \mathrm{A} \cdot 599.8\ \Omega = 72.0\ \mathrm{V}$, giving $I_1 = 72.0\ \mathrm{mA}$, $I_2 = 32.7\ \mathrm{mA}$, $I_3 = 15.3\ \mathrm{mA}$, which sum to $120\ \mathrm{mA}$.
Worked Solution
Assumed branch currents for the three-way divider
Given: $I_T = 120\ \mathrm{mA}$, $R_1 = 1000\ \Omega$, $R_2 = 2200\ \Omega$, $R_3 = 4700\ \Omega$. Total resistance: $$\frac{1}{R_T} = \frac{1}{1000} + \frac{1}{2200} + \frac{1}{4700} = 1.000 + 0.4545 + 0.2128 = 1.667\ \mathrm{mS}$$ $$R_T = \frac{1}{1.667 \times 10^{-3}} = 599.8\ \Omega$$ General current divider: $$I_2 = \frac{R_T}{R_2} \cdot I_T = \frac{599.8}{2200} \cdot 120\ \mathrm{mA} = 0.2726 \cdot 120\ \mathrm{mA} = 32.7\ \mathrm{mA}$$ Check through the common voltage: $V = I_T R_T = 0.120 \cdot 599.8 = 72.0\ \mathrm{V}$, and $72.0/2200 = 32.7\ \mathrm{mA}$.
Problem 10
Ch. 6 — Power in One Branch
A $9.0\ \mathrm{V}$ source is across a $220\ \Omega$ resistor and a $1.0\ \mathrm{k\Omega}$ resistor in parallel. How much power does the $220\ \Omega$ resistor dissipate, in milliwatts?
Two parallel branches across a 9.0 V source
Find the power $P_1$ dissipated by the $220\ \Omega$ resistor.
Solution
368 mW
Step 1List the knowns: $V_S = 9.0\ \mathrm{V}$, $R_1 = 220\ \Omega$, $R_2 = 1.0\ \mathrm{k\Omega}$. Asked: power in $R_1$.
Step 2Describe the model: the two resistors are in parallel, so each has the full $9.0\ \mathrm{V}$ across it. The other branch and the total resistance are not needed.
Step 3Set the convention: power dissipated in a resistor is positive; work in volts, ohms and watts.
Step 4Write the power formula in its voltage form: $$P_1 = \frac{V_S^2}{R_1}$$ It is the convenient form because voltage is the shared quantity.
Step 5Substitute the numbers: $$P_1 = \frac{(9.0\ \mathrm{V})^2}{220\ \Omega}$$
Step 6Square the voltage: $9.0^2 = 81\ \mathrm{V}^2$.
Step 7Divide: $P_1 = 81 / 220 = 0.3682\ \mathrm{W}$.
Step 8State the result: $P_1 = 368\ \mathrm{mW}$.
Step 9Check: $\mathrm{V}^2/\Omega = \mathrm{W}$. The $1.0\ \mathrm{k\Omega}$ branch dissipates $81/1000 = 81\ \mathrm{mW}$, so the smaller resistor runs hotter. A $1/2\ \mathrm{W}$ part would be the minimum sensible rating.
Worked Solution
Given: $V_S = 9.0\ \mathrm{V}$, $R_1 = 220\ \Omega$. The voltage is common, so use $P = V^2/R$: $$P_1 = \frac{V_S^2}{R_1} = \frac{(9.0\ \mathrm{V})^2}{220\ \Omega} = \frac{81}{220} = 0.368\ \mathrm{W} = 368\ \mathrm{mW}$$ Units: $\mathrm{V}^2/\Omega = \mathrm{W}$. The $1.0\ \mathrm{k\Omega}$ branch dissipates only $81\ \mathrm{mW}$; in parallel the smallest resistance runs hottest.
Problem 11
Ch. 6 — Total Power in a Parallel Circuit
A $15\ \mathrm{V}$ source is across three resistors in parallel: $R_1 = 1.5\ \mathrm{k\Omega}$, $R_2 = 3.3\ \mathrm{k\Omega}$ and $R_3 = 4.7\ \mathrm{k\Omega}$. Find the total power delivered by the source, in milliwatts.
Three parallel branches across a 15 V source
Find the total power $P_T$.
Solution
266 mW
Step 1List the knowns: $V_S = 15\ \mathrm{V}$, $R_1 = 1.5\ \mathrm{k\Omega}$, $R_2 = 3.3\ \mathrm{k\Omega}$, $R_3 = 4.7\ \mathrm{k\Omega}$. Asked: total power $P_T$.
Step 2Describe the model: three parallel branches, each with the full $15\ \mathrm{V}$ across it; total power is the sum of the branch powers.
Step 3Set the convention: dissipated power is positive; work in volts and ohms, then convert watts to milliwatts.
Step 4Write the branch power formula: $$P_x = \frac{V_S^2}{R_x}$$ Voltage is common, so this form needs no currents.
Step 5Substitute the numbers for each branch: $$P_1 = \frac{225}{1500}\ \mathrm{W}, \quad P_2 = \frac{225}{3300}\ \mathrm{W}, \quad P_3 = \frac{225}{4700}\ \mathrm{W}$$
Step 6Evaluate: $P_1 = 150\ \mathrm{mW}$, $P_2 = 68.2\ \mathrm{mW}$, $P_3 = 47.9\ \mathrm{mW}$.
Step 7Write the total power rule: $$P_T = P_1 + P_2 + P_3$$
Step 8Add and state the result: $P_T = 150 + 68.2 + 47.9 = 266\ \mathrm{mW}$.
Step 9Check by a second route: $R_T = 1/(1/1500 + 1/3300 + 1/4700) = 845.7\ \Omega$, and $225/845.7 = 266\ \mathrm{mW}$. The two routes agree, and the smallest resistor dissipates the most.
Worked Solution
Given: $V_S = 15\ \mathrm{V}$, so $V_S^2 = 225\ \mathrm{V}^2$. Each branch: $$P_1 = \frac{225}{1500} = 150\ \mathrm{mW}, \quad P_2 = \frac{225}{3300} = 68.2\ \mathrm{mW}, \quad P_3 = \frac{225}{4700} = 47.9\ \mathrm{mW}$$ Total: $$P_T = P_1 + P_2 + P_3 = 150 + 68.2 + 47.9 = 266\ \mathrm{mW}$$ Check from the total resistance: $R_T = 845.7\ \Omega$, and $225/845.7 = 0.266\ \mathrm{W}$.
Problem 12
Ch. 6 — Locating an Open Branch
Three resistors are in parallel across a $24\ \mathrm{V}$ source: $R_1 = 820\ \Omega$, $R_2 = 1.2\ \mathrm{k\Omega}$ and $R_3 = 2.7\ \mathrm{k\Omega}$. A voltmeter reads $24\ \mathrm{V}$ across every branch, but an ammeter in the source lead reads only $38.2\ \mathrm{mA}$. One branch has failed open. Find how much current is missing from the expected total, and use it to identify the open branch.
Three-branch parallel circuit with a suspected open
Find the current missing from the expected total (and state which branch is open).
Solution
